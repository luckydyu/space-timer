# 우주 초스피드 학습 타이머

아이의 학습지 풀이 시간을 게임처럼 기록하는 정적 웹 앱입니다. 로켓과 목적지를 고르고, 각 장을 시작/완료하면서 랩타임을 쌓아 최종 기록을 확인합니다.

## 주요 기능

- 장 수 설정
- 로켓/도착지 선택 및 랜덤 미션 뽑기
- 터치 또는 음성 명령으로 미션 시작/완료
- 랩타임, 누적 시간, 평균/최단 기록 표시
- 결과 화면과 축하 효과
- 첫 화면에서는 마이크를 실제로 켜지 않고, 첫 미션 화면부터 음성 인식 시작

## 실행

이 앱은 빌드 없이 `index.html`만으로 동작합니다.

```bash
npm install
npm test
```

브라우저에서 직접 확인하려면 `index.html`을 열거나, 테스트용 정적 서버를 사용할 수 있습니다.

```bash
node tests/helpers/serve-static.mjs
```

그 다음 브라우저에서 `http://127.0.0.1:4173`으로 접속합니다.

## 테스트

Playwright로 핵심 회귀 테스트를 돌립니다.

```bash
npm test
```

현재 테스트는 다음 흐름을 확인합니다.

- 초기 설정 화면 표시
- 첫 화면에서 음성 인식이 바로 시작되지 않음
- 장 수 변경
- 1랩 경기 시작/완료/결과 표시
- 결과 화면에서 다시 시작
- 음성 인식 mock을 사용한 시작/완료 명령 흐름

## 린트

```bash
npm run lint
```

린트는 두 가지를 확인합니다.

- ESLint로 프로젝트의 JavaScript 파일 검사
- `index.html` 안의 인라인 `<script>` 문법 검사

## 배포

GitHub Pages에서 루트의 `index.html`을 서빙하면 됩니다. 현재 구조는 빌드 과정이 필요 없습니다.

앞으로 파일을 나눌 때도 `./src/main.js`, `./styles/app.css`처럼 상대 경로 기반의 브라우저 ES Modules를 사용하면 GitHub Pages에서 그대로 동작합니다.

## 개발 메모

- `node_modules/`, `test-results/`, `playwright-report/`, `debug.log`는 커밋하지 않습니다.
- Web Speech API는 브라우저 지원과 사용자 권한 상태에 영향을 받습니다.
- 실제 마이크는 테스트하지 않고, Playwright 테스트에서는 mock으로 음성 인식 흐름을 검증합니다.
